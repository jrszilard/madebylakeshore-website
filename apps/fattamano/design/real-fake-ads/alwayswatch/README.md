# AlwaysWatch Blind Spot Vault

Real Fake Ads concept for a fictional surveillance vendor selling a useful anti-surveillance object: offline password/recovery-code storage using obsolete media metaphors.

## Files

- `alwayswatch-blind-spot-vault-ad.html` — editable poster/ad concept.

## Product direction

- **Legacy Disk Edition:** 3D printed floppy cards + divider tabs by category.
- **Burned Disc Edition:** 3D printed CD cards + CD case/binder category sections.
- Category tabs identify account types; the individual floppy/CD cards hold the written sensitive details.

Safety note: position as an offline organizer, not a fireproof/waterproof/burglar-proof safe.
