# Local Copy Department

Real Fake Ads campaign for anti-cloud physical media infrastructure.

## Core line

**If you can hold it, they can't sunset it.**

## First ad/product concept

**The Cloud, Locally Hosted** — a 3D printed cloud-shaped USB-drive holder.

## Intended product family

- USB-drive cloud holder
- DVD/Blu-ray rack
- CD rack
- SD/microSD archive tray
- USB label flags/tags

## 3D workflow

Physical product designs should be created in `ai-projects/3d-printing`, starting with:

```txt
parts/media/usb-cloud-holder/
```

Use the CadQuery → preview → verify-slice → print → QA loop from the 3D-printing platform.
